# Contributing

1. Create a Git Flow feature branch from `develop`.
2. Add or update one self-contained directory under `skills/`.
3. Keep the skill name lowercase and hyphen-separated.
4. Review every bundled script and third-party license.
5. Run `python3 scripts/validate_skills.py`.
6. Open a pull request into `develop`.

Changes promoted to `main` should use a Git Flow release or hotfix branch.
